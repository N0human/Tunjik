# Игры Пружинок

Спецификация первого выпуска: 14 игр, правила допуска к каждой, формулы звёзд и список сознательно отклонённых механик. Игра — это способ проверки одного умения; если две игры проверяют одно и то же, вторая лишняя.

## 1. Две семьи

**Экранные** — своё поле и свой жизненный цикл: счёт ходов, отметки на доске, оценка ученика. Три игры: `pairs`, `bingo`, `srs`.

**Раундовые** — одна форма вопроса и общий цикл раунда: обратный отсчёт, пять жизней, немедленная обратная связь, финал со звёздами. Одиннадцать игр. Новая раундовая игра — это одна функция-генератор плюс вид, а не новая архитектура.

## 2. Общие правила

**Нормализация ответа** применяется ко всему свободному вводу и к дедупликации вариантов: обрезка, нижний регистр, удаление знаков препинания, включая армянские `՛ ՞ ։ ՜` и латинские `, . ! ? ' ’ ( ) -`, схлопывание пробелов. Для ответа на английском сравнение регистронезависимое.

**Нечёткое совпадение** при вводе: расстояние Левенштейна с допуском `max(2, длина / 8)` и ранним выходом при разнице длин больше трёх. Возможны три исхода — `exact`, `fixed`, `retry`. `fixed` показывает канонический вариант как мягкую поправку, а не как ошибку: в игре на письмо это полезнее, чем сигнал о неверности.

**Отвлекающие варианты** подбираются не случайно. Кандидат получает +2 за ту же тему, +2 за ту же часть речи и +1 за разницу длины не больше двух; затем seeded-перемешивание и стабильная сортировка, чтобы порядок внутри равных оценок не был предсказуемым. Варианты дедуплицируются по нормализованному ответу, правильный ответ входит ровно один раз, всего их ровно четыре. Если кандидатов не хватает — добираются из остального пула.

**Ошибка** тратит одну жизнь. Пять жизней, конец раунда при нуле. Никогда не сохраняются и не переносятся между играми.

**Таймер** обратный отсчёт, по умолчанию 60 секунд, настраивается и может быть выключен. Держит абсолютный `endsAt`, а не счётчик: браузер душит таймеры в фоновой вкладке, и раунд на минуту иначе не заканчивается.

**Детерминизм.** Генератор случайных чисел внедряется, поэтому один и тот же `seed` даёт одну и ту же последовательность вопросов. Без этого падение не воспроизводится, и тест бесполезен.

## 3. Звёзды

Правила не взаимозаменяемы: у экранных игр ошибок либо нет по построению, либо их число не равно доле верных ответов.

| Правило | Формула |
| --- | --- |
| По ошибкам | 0 ошибок → 3★; 1–2 → 2★; 3–5 → 1★; больше 5 → 0★ |
| По доле верных | `min(3, ceil(3 · верные / всего))`, при нуле ответов — 0 |
| Раундовые | **минимум** из двух верхних |
| `bingo` | по ошибкам |
| `pairs` | по лишним ходам: 0 → 3★; не больше половины пар → 2★; не больше числа пар → 1★; больше → 0★ |
| `srs` | звёзд нет; в финале сводка по четырём оценкам |

Минимум в раундовых играх обязателен: раунд на 60 секунд без единой ошибки, но с тремя верными из двадцати, не должен давать три звезды.

## 4. Правила допуска

Игра доступна в колоде, только если в колоде хватает материала её требованиям. Доступность **вычисляется** из содержимого колоды, а не задаётся вручную: иначе при смене словаря список начнёт врать.

| Игра | Требования к элементу | Минимум в колоде |
| --- | --- | ---: |
| `quiz`, `reverse`, `typing`, `dictation` | есть перевод на языке интерфейса | 4 |
| `listen` | есть озвучка, не скрытая настройкой | 4 |
| `bingo` | есть озвучка; переводы на поле попарно различны после нормализации | 6, доска сжимается до 2×3; ниже — недоступна |
| `catch-letter` | `kind: word`, длина не меньше 3 | 4 с различными первыми буквами |
| `constructor` | `kind: word`, длина 3–9 | 3 |
| `translit` | `kind: word`, есть перевод | 4 |
| `number-marathon` | значение из активного диапазона 0–999 | 4 |
| `fill-letter` | `kind: word`, есть позиция буквы, встречающейся ровно один раз | 4 |
| `odd-one` | `kind: word` **и** заданная тема | 4, из них три одной темы |
| `pairs` | 8 пар с попарно различными нормализованными значениями | 8 |
| `srs` | есть карточка или вводимое слово | 1 |

Три следствия, которые надо принять как норму:

- `catch-letter` на фразе `Ո՞վ ես` и на числе бессмыслен, на двухбуквенном элементе ответ тривиален, поэтому и то и другое исключено. Понятно, что это отсекает буквы `Ա`/`Բ` из активного словаря — они и не должны попадать в игру про первую букву слова.
- `constructor` на трёхсловной фразе непроходим, поэтому берутся только слова длиной 3–9.
- `odd-one` требует тему, а значит **недоступна** на уровневых колодах и на колоде «Грамматика». Это ограничение отображается в интерфейсе, а не приводит к пустому экрану.

## 5. Экранные игры

### `pairs` — Пары

Поле 4×4: восемь пар «армянское слово ↔ значение». Ход открывает две плитки; совпадение убирает пару, несовпадение возвращает плитки. Ошибок нет, поэтому оценивается не число промахов, а число ходов: минимум — восемь.

Недоступна в колоде, где меньше восьми элементов с различимыми значениями: пары нельзя строить из повторов, иначе две одинаковые плитки дадут ложную пару.

### `bingo` — Аудио-бинго

Поле 3×3 из значений на языке интерфейса. Звучит слово, ученик отмечает подходящую клетку. Верная клетка засчитывается, неверная тратит жизнь, после верной отметки звучит следующее слово. Девять отметок — финал.

Требование уникальности значений на поле не косметическое: две одинаковые клетки делают игру нечестной, потому что верными становятся обе.

Отличие от `dictation` принципиальное: бинго тренирует **различение на слух** среди видимых вариантов, диктант — **фонографию**. Обе игры остаются.

### `srs` — Карточки

Классические карточки SM-2. Смысл скрыт до оценки, четыре оценки, пачка ограниченного размера, сессия идёт по подошедшим по времени карточкам. Ошибок и звёзд нет: оценку даёт ученик, и подмена её вычислением была бы ложью.

## 6. Раундовые игры

| id | Название | Вопрос | Что считается ошибкой |
| --- | --- | --- | --- |
| `quiz` | Выбор | армянское слово, четыре значения | любой неверный выбор |
| `reverse` | Наоборот | значение, четыре армянских слова | любой неверный выбор |
| `listen` | Услышал | только озвучка, четыре значения | любой неверный выбор |
| `catch-letter` | Поймай букву | слово, четыре первые буквы | неверная буква |
| `typing` | Пишем слово | значение, поле ввода армянского текста | `retry`, то есть расхождение больше допуска |
| `dictation` | Диктант | озвучка, поле ввода | `retry` |
| `constructor` | Собери слово | значение, перемешанные буквы | неверная сборка, включая неполную |
| `translit` | Армянскими буквами | перевод, записанный армянскими буквами (`փրիվետ`), четыре значения | любой неверный выбор |
| `number-marathon` | Числа | число арабскими, четыре варианта словами или наоборот | неверное число |
| `fill-letter` | Допиши | слово с одной пропущенной буквой, четыре буквы-кандидата | неверная буква |
| `odd-one` | Чужой | четыре слова, три из одной темы, один из другой | названное слово не то |

### Требования, которые не видно в таблице

**`listen`.** Варианты ответа **заблокированы до первого прослушивания**. Без этого игра превращается в угадывание по длине слова, а не в аудирование. Повторное прослушивание не штрафуется и целиком входит во время ответа в журнале. Если записи нет или показ непроверенных озвучек выключен, режим недоступен с объяснением причины.

**`typing` и `dictation`.** Подсказка транслитерацией по умолчанию выключена: подсказка превращает письмо в угадывание. Исход `fixed` показывает написанное правильно, но не подтверждает память.

**`constructor`.** Перемешивание обязано давать неверный порядок с первой попытки, как в соседнем проекте, иначе задача решается без действий.

**`fill-letter`.** Удалять можно только букву, встречающуюся в слове ровно один раз. Иначе правильными окажутся несколько позиций, и задача станет неоднозначной. Если подходящей позиции нет — берётся другое слово.

**`number-marathon`.** Слова берутся из генератора 0–999, а не из чужого списка записей. Форма — неопределённая: `տաս`, `տասնմեկ`, քսան, `իննսունի`, а не `տասը`. Озвучка генерируется из того же вызова, поэтому текст вопроса и текст записи не могут разойтись.

**`translit`.** Словарь русского и английского текста переводится в армянские буквы по звуковому принципу. Это не загадка и не обман: задача в том, чтобы прочесть армянское на слух, а не угадать. Происхождение подмены показывается в интерфейсе.

**`odd-one`.** Механика автоматическая, а вот вопрос, действительно ли слово «чужое», — редакторский. Слово из другой темы может иметь значение, близкое к теме, и задача станет двусмысленной. Такие случаи отмечаются при импорте и правятся в содержании, а не подгонкой правила.

## 7. Смешанный раунд

Переключатель колоды, а не карточка в хабе: режим выбирается случайно на каждый вопрос из набора, доступного в этой колоде. Три строки кода и один честный способ потренировать всё подряд без шести нажатий.

## 8. Отклонено и почему

| Игра соседнего проекта | Причина отказа |
| --- | --- |
| `guess`, `sprint`, `daily` | тот же вопрос с вариантами; различаются только таймером и записью за день. Это параметры сессии |
| `duel` | тот же вопрос с вариантами плюс маскот, которого в первом выпуске нет |
| `odd-one-out` | объявлена «что лишнее», но сводится к обычному вопросу с вариантами |
| `chain` | «выбери слово на эту букву» вырождается в угадывание, когда в группе одно слово |
| `reverse` | дефект: правильный ответ всегда первый вариант |
| `catch-letter` | дефект: варианты берутся из начала списка без перемешивания, их может оказаться меньше четырёх |
| `constructor` | токены собираются из транслитерации — тренируется латиница, а не армянское слово |
| `true-false` | два варианта ответа почти не отличаются от угадывания и не добавляют ничего к `quiz` |
| Маскот, опыт, наклейки, конфетти | см. продуктовый план, раздел 9 |

Итого из 13 игр хаба соседнего проекта самостоятельными являются восемь. Пять — это один и тот же вопрос с вариантами под разными именами, иконками и таймерами, и переносить их как тринадцать игр означало бы выдать переименование за функциональность.
