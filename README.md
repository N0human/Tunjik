# Пружинки / Թունջիկներ

**Игры для запоминания армянских слов.** Дополнение к [Arahet](../Arahet): та же визуальная система, та же бумага и шрифты, другой акцентный цвет и игровой характер.

Название — `թունջիկ`, уменьшительное от `թունջ` «прыгать», то есть «попрыгунчик, прыгающая игрушка». Русское «Пружинки» — игровая калька по образу пружинящей игрушки, а не буквальный перевод. Это указано и в интерфейсе, и здесь: в этом приложении названия и адаптации не выдаются за перевод.

## Названия в магазинах

Латиница для англоязычных магазинов: `Tunjik`, прямая транслитерация `թունջիկ`. Основание — прецедент Arahet, где `Արահետ` становится `Arahet`. `Springs` и `Bounce` понятнее, но дженерик: `Bounce` сильно занят в Play Store, а `Springs` не защищается как бренд. Имя в магазинах не работает на поиск — запрос покупателя «learn Armenian», а не «spring», поэтому смысл несут подзаголовок и ключевые слова.

| Локаль | Название | Подзаголовок |
| --- | --- | --- |
| ru | Пружинки | Игры для запоминания слов |
| en | Tunjik | Armenian word games |
| hy | Թունջիկներ | Խոսքերի խաղեր՝ բառեր հիշելու համար |

Все значения укладываются в ограничение в 30 символов. Ключевые слова: `armenian, vocabulary, words, learn, game, puzzle, practice, eastern armenian` и `армянский, слова, запомнить, игра, восточноармянский`.

Класс 28 — игры и игрушки, класс 41 — образование. Регистрация действует только в Китае и не препятствует охране в РФ, ЕС и США, но она означает, что **строка `TUNJIK` уже занята как способ транслитерации** и не является различительным обозначением в глазах реестра. Первоначальное соображение «имя редкое, поэтому свободное» для товарного знака неверно: редкость помогает в магазине, а не в реестре.

**Отдельно про `ARMGAMES`.** Существует российский бренд: GitHub-аккаунт `ARMGAMES`, `armgames.ru`, 11 репозиториев, с 2016 года. Название каталога проекта свободно для публикации в магазинах, но **использовать `ArmGames` как бренд или как корневую часть идентификатора приложения нельзя**. Идентификатор Android (`appId`) нужно зафиксировать один раз до первой публикации: после создания листинга он не меняется. Предложение — `com.tunjik.games`.

**Что сделать до публикации:** проверить `Tunjik`, `Tunjik Words` и `Tunjik: Armenian` в USPTO, WIPO Global Brand Database и реестре ФИПС вручную — три источника не были достигнуты автоматически, и ФИПС здесь главный, потому что основной рынок русский. Если `TUNJIK` нужен как словесный знак, его стоит заявить самому: в проверенной выборке базовое слово в классах 9, 41 и 42 не занято.

## Локальный запуск

Требуется Node.js 22 или новее.

```sh
npm install
npm run dev
```

Команды: `npm run build` (внутри — `validate:content` и `tsc -b`), `npm run typecheck`, `npm test`, `npm run test:e2e`, `npm run preview`. Скрипты аудиоконвейера и `validate:audio` появятся вместе с фазами 2 и 10 — в `package.json` их пока нет, чтобы не предлагать команды, которые падают с «файл не найден». Для публикации в подкаталоге задайте `DEPLOY_BASE_PATH=/Пружинки/ npm run build`.

## Что задумано

Приложение не заменяет учебный маршрут Arahet, а использует накопленный им словарь иначе: не «пройти урок», а «потренировать то, что уже знаешь». Ученик выбирает игру и колоду, игра отбирает слова, проверяет их тем способом, который тренирует нужное: узнавание, на слух, письмо, порядок букв, скорость.

- **2141 активная запись** словаря: 188 элементов Arahet (учебная лексика и грамматика) плюс 1953 тематических слова из проекта `aybuch`, за вычетом 47 совпадений.
- **Колоды** строятся поверх 15 тем словаря `aybuch`, поэтому темы не размечались вручную. Отдельные колоды есть по уровням A1–B2, есть «Всё подряд» и «Грамматика».
- **14 игр:** три экранные с собственным полем (`pairs`, `bingo`, `srs`) и одиннадцать раундовых с общей формой вопроса.
- **Повторение** — SM-2 с коэффициентом лёгкости, лapses, порогом «трудного слова» и зрелостью карточки.
- **Награда** — звёзды, жизни в рамках сессии и таймер. Без опыта, уровней, стикеров и маскота.
- **Прогресс** — отдельная база `armgames-progress`; с Arahet не разделяется.

## Ограничения, зафиксированные заранее

- **Лицензия аудиомодели.** Модель `hy_AM-tigran_nune-medium` распространяется как GPL-2.0. Право распространять сгенерированные ею записи для этого приложения **не проверено** и является блокером выпуска. Наследуется от обоих соседних проектов.
- **Речевая проверка не пройдена.** Ни один из 3139 материалов не прослушан носителем — это 6278 файлов в двух голосах. Все помечены `reviewed: false`, кнопки прослушивания видны, подпись о синтетической озвучке показывается всегда.
- **Переводы A2–B2 не вычитаны** — 1200 слов из словаря `aybuch` взяты как есть и помечаются в интерфейсе.
- **Прогресс только на устройстве.** Экспорта и импорта в файл нет, это написано в настройках, а не спрятано. Очистка данных приложения уничтожает весь путь безвозвратно.
- **Словарь — общий с Arahet по происхождению, но не по базе.** Статистика и карточки живут только здесь; прогресс Arahet не читается и не обновляется.
